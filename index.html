Install the models

Windows, one file, one double-click. Safe to re-run, and undoable.

Set pz-godot up first.

The models carry no Project Zomboid art. They are textured at runtime from the atlas you build from your own copy of Build 42, so run pz-godot's setup.bat before installing these, or everything renders in flat colours.

Download install-models.bat

Drag it into your pz-godot folder, next to project.godot, and double-click it. It fetches its own installer script the first time it runs.
